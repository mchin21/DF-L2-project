Instructions for running the file:
- Download the jupyter notebook (main.ipynb) from Github
- Download the data files (data.zip) and unzip the folder to access individual .csv files
- Download all requirements listed in requirements.txt 
- To install all requirements, input this command in your terminal: "pip install -r requirements.txt"
- Open the notebook in your text editor and click "Run All"

Data visualization tests:
- After clicking "Run All", four bar graphs will populate
- The titles of the bar graph are "DF Performance ESL", "DF Performance English L1",
"False Alarm Rates (New Items) - English L1" and "False Alarm Rates (New Items) - ESL"
- Each graph has two categories: Easy Words and Hard Words
- Each category has two bars: a blue bar (R-items) and an orange bar (F-items)
- Each bar has an error bar indicating the standard deviation from the mean

Descriptive statistics tests:
- After clicking "Run All", descriptive statistics for each participant group prints above the
corresponding bar chart
- Each readout contains the average, standard deviation, and the number of files read for each analysis
